# Guidance Manual for Returns Management System (RMS)

A SAMA user/guidance manual explaining how supervised entities access the Returns Management System (RMS) portal and submit, validate and resubmit supervisory and prudential returns for each reporting period. It is procedural rather than substantive: it covers account creation by SAMA, period-opening notifications, template-based file upload, validation, submission and the resubmission request route where the supervisor raises observations. It binds/serves entities under SAMA supervision that are required to file periodic returns, and the SAMA supervisory staff who review, accept or return them.

**Regimes:** governance/risk, banking prudential
