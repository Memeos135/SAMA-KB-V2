# SAMA Cyber Security Framework

A concept node for the SAMA Cyber Security Framework as a companion instrument cross-referenced from the IT Governance Framework and related SAMA circulars. It is the source of cyber security control requirements (for example, cyber security review and approval of changes before CAB submission and definition of security requirements for system changes) that Member Organizations must satisfy alongside IT governance controls. It binds organisations regulated by SAMA and is used by SAMA to assess control maturity.

**Regimes:** governance/risk

### [[IT Governance Framework]] — `references` [EXTRACTED]
- **What this link tells you:** An institution cannot demonstrate IT governance compliance by reading the IT Governance Framework alone; cyber security and business continuity controls must be sourced from the dedicated frameworks. The IT Governance Framework expressly defers to SAMA's Cyber Security Framework (and the Business Continuity Management Framework) for those specific requirements, creating a signposted obligation chain rather than a duplicate standard. The consequence is that gap assessments, maturity ratings and remediation plans must be run against the cyber framework's requirements where the subject matter is cyber, with IT governance supplying the surrounding accountability structure.
