# Cyber Security Event Management

A control area of the SAMA Cyber Security Framework on cyber security event management — the logging, monitoring, analysis and escalation of security events — assessed against the Framework's six-level maturity model. It connects to the policy requirement that cyber security breaches and suspected weaknesses be reported and that cyber security be reflected in business continuity management, with defined roles and ultimate Board responsibility. It binds Member Organizations supervised by SAMA.

**Regimes:** governance/risk
