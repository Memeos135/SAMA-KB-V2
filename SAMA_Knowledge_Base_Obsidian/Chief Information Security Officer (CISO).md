# Chief Information Security Officer (CISO)

Defines the information security function headed by a Chief Information Security Officer, which must be independent of the IT function and report to the CEO/managing director or the general manager of a control function. The role covers security policy support, defining roles and goals, providing security and information risk management frameworks, identifying emerging issues and risk-appetite shifts, and assisting management with security processes and controls. It applies to Member Organizations under SAMA supervision.

**Regimes:** governance/risk
