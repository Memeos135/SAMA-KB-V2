# Infrastructure Security

Requires Member Organizations to define, approve and implement cyber security standards for infrastructure components, monitor compliance with those standards, and measure and periodically evaluate their effectiveness. It follows directly from the change management controls and sits within the Framework's policy, roles and maturity-model architecture, with the Board ultimately accountable. Applies to entities supervised by SAMA.

**Regimes:** governance/risk
