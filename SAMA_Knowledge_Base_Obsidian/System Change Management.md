# System Change Management

This node sets out the System Change Management domain of SAMA's IT Governance Framework, covering governance of changes to information assets, change requirement definition and approval, system acquisition, testing, security requirements, release and configuration management, and patch management. Changes must be classified, risk-assessed, tested and approved (including Change Advisory Board endorsement and cyber security function review consistent with the SAMA Cyber Security Framework) before production deployment, with emergency changes documented and root-caused after the fact. It binds Member Organizations and their change requestors, asset owners, CAB and cyber security function.
