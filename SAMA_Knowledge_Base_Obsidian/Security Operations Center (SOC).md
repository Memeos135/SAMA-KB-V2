# Security Operations Center (SOC)

Concept node in the SAMA Cyber Security Framework tying the Security Operations Center to the framework's maturity model and governance layer: the SOC is the designated team required under cyber security event management, and its adequacy is assessed against maturity levels 0–5 (target levels require all preceding criteria to be met). Governance context includes the board's ultimate responsibility for cyber security, budget and policy approval, and defined cyber security roles. Binds Member Organizations supervised by SAMA.

**Regimes:** governance/risk
