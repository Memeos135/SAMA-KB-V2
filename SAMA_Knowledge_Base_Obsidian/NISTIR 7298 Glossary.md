# NISTIR 7298 Glossary

A concept node for the glossary underpinning the Cyber Resilience Fundamental Requirements, where key terms (e.g. cyber security governance, cyber security incident, cyber security policy, availability, audit, business continuity) are defined by reference to NISTIR 7298r3 and ISO 22301. It supplies the defined-term layer used to interpret the control requirements rather than imposing obligations itself. Relevant to anyone construing scope of terms in SAMA cyber resilience instruments.

**Regimes:** governance/risk, other
