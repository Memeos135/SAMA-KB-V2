# Financial Action Task Force

Defined term in the Guide to Rules Governing Banks' Remittance Centers describing the Financial Action Task Force as the inter-governmental standard-setter for AML, terrorist financing and proliferation financing measures. It serves as the reference framework underpinning the Guide's CDD, beneficial owner identification, risk-based approach and KYC obligations for remittance centres. Relevant to banks' remittance centres and licensed remittance companies applying SAMA's AML/CFT rules.

**Regimes:** AML/CTF, payments
