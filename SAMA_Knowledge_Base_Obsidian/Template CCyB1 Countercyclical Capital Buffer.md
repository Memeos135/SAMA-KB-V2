# Template CCyB1: Countercyclical Capital Buffer

Node for Pillar 3 Template CCyB1, which discloses the geographical distribution of private sector credit exposures used to calculate a bank's institution-specific countercyclical capital buffer. It defines what must be reported per jurisdiction (buffer rate in force, exposure values, RWA) and how the bank-specific weighted-average buffer rate and resulting buffer amount are derived, excluding pre-announced rates not yet applicable. The surrounding context also covers Template CDC on capital distribution constraints, which references buffer stacking.

**Regimes:** banking prudential
