# System Configuration Management

Provision requiring Member Organizations to define, approve, communicate, implement and periodically evaluate a system configuration management process that maintains reliable and accurate information about configuration items for their information assets. It addresses roles and responsibilities, identification and criticality of configuration items relative to supporting business processes, interrelationships between items, periodic verification, and implementation of a configuration management database. Binds Member Organizations supervised by SAMA.

**Regimes:** governance/risk
