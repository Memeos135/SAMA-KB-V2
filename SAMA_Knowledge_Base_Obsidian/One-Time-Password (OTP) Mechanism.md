# One-Time-Password (OTP) Mechanism

This node covers the one-time-password requirements in the Minimum Verification Controls. OTP is required as a registration verification factor sent to a trusted-party-verified phone number, and for defined operational events including first-time wallet-to-wallet transfers below a defined value, marketplace transactions, first-time bill/utility/government payments, password resets, wallet reactivations and company-assessed risky transactions; out-of-band OTP delivery (a different channel) is required for higher-exposure transactions such as wallet transfers above the defined daily value, first-time IBAN transfers, international transfers and high-risk transactions. The defined value is set and periodically revised by separate SAMA memo, so the threshold is not fixed in the document itself. Binds member organizations providing e-wallet, lending, crowdfunding or other fintech services under SAMA supervision.

**Regimes:** payments, governance/risk, BNPL/finance
