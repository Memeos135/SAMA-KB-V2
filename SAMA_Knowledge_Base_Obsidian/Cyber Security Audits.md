# Cyber Security Audits

A sub-domain of the SAMA Cyber Security Framework dealing with periodic independent review and audit of compliance with cyber security controls, read against the Framework's six-level maturity model (levels 3 and above require cumulative satisfaction of lower levels). It sits alongside the requirements for a board-endorsed cyber security policy and defined roles, with the Board holding ultimate accountability including budget and approvals. It binds Member Organizations supervised by SAMA and is assessed by SAMA through the maturity model.

**Regimes:** governance/risk
