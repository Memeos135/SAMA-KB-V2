# SAMA FEER Framework

This node is a concept entry for the SAMA FEER framework as cross-referenced from the Financial Sector Cyber Threat Intelligence Principles. The supplied context does not set out FEER's own content; it only shows the CTI expectations on delivering actionable intelligence, internal sharing and continuous improvement of intelligence methods. Open the underlying CTI Principles document (and the separate FEER instrument) to confirm the actual scope and obligations before relying on this node.
