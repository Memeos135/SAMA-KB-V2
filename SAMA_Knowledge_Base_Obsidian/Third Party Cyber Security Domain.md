# Third Party Cyber Security Domain

A domain node of SAMA's Cyber Security Framework addressing cyber security risk arising from outsourcing, cloud, vendors and other external service providers engaged by a Member Organization. It requires third-party arrangements to be governed by defined, approved cyber security requirements with contractual obligations and periodic measurement of effectiveness, consistent with the framework's maturity expectations. Responsibility remains with the Member Organization and its Board regardless of the outsourcing.
