# Table MRB: Qualitative Disclosures IMA

Table MRB sets the qualitative Pillar 3 disclosure requirements for banks with SAMA approval to use the internal models approach (IMA) for market risk, covering model scope, trading desk eligibility, validation, backtesting and P&L attribution arrangements. It provides the narrative context for the IMA quantitative templates. Binds only banks permitted to use the IMA.

**Regimes:** banking prudential, governance/risk
