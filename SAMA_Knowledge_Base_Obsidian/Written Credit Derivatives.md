# Written Credit Derivatives

Defines written credit derivatives broadly as any arrangement under which a bank effectively provides credit protection — not only credit default and total return swaps but also sold options — and sets the conditions for reducing the effective notional amount, including negative fair value adjustments and offsetting against purchased protection. Offsetting requires the same or more conservative material terms (subordination, optionality, credit events, reference obligation), identical legal-entity reference names, and equivalent economic coverage where pools of names are involved. Binds SAMA-supervised banks calculating derivative exposures for the leverage ratio exposure measure.

**Regimes:** banking prudential
