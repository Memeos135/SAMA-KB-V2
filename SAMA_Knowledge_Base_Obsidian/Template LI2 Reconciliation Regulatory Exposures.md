# Template LI2: Reconciliation Regulatory Exposures

Node covering Template LI2, the Pillar 3 disclosure explaining the main sources of difference between financial statement carrying values (on the regulatory consolidation scope, per LI1) and the exposure amounts used for regulatory capital purposes — including off-balance sheet amounts, valuation differences, netting rules, provisions and prudential filters. It is annual, flexible in format, and supported by narrative in Table LIA. It is mandatory for all banks subject to the Pillar 3 framework.

**Regimes:** banking prudential, governance/risk
