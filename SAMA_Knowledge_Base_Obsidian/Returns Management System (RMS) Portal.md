# Returns Management System (RMS) Portal

Concept node for SAMA's Returns Management System (RMS), the supervisory reporting portal through which SAMA-supervised entities submit prescribed prudential/supervisory return forms and through which SAMA supervisors review, accept or return them. The underlying material is a user guidance manual (account creation, submission, resubmission after supervisory observations) together with a circular applying the system to money exchange centres, which must file monthly, quarterly and annual supervisory returns within stated deadlines after period end. Relevance is operational-regulatory: it evidences the enforceable channel and timing for regulatory data submission rather than substantive conduct rules.

**Regimes:** governance/risk, banking prudential, other
