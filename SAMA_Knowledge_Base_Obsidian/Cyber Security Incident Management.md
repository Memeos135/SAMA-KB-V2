# Cyber Security Incident Management

A control domain of the SAMA Cyber Security Framework dealing with how Member Organizations detect, respond to, escalate and report cyber security incidents, including reporting of breaches and suspected weaknesses to SAMA and internal stakeholders. It sits within the Framework's overall structure of governance, policy, defined roles and the six-level cyber security maturity model against which compliance is assessed. It binds SAMA-supervised Member Organizations (banks, insurers, finance companies and similar entities), with ultimate accountability resting with the Board.

**Regimes:** governance/risk
