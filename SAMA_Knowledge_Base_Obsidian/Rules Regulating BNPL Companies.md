# Rules Regulating BNPL Companies

Node identifying the Rules Regulating Buy Now Pay Later (BNPL) Companies as the instrument that, together with the Finance Companies Control Law, provides the licensing provisions and defined terms for BNPL activity. Here it appears only as the interpretive source for terms used in SAMA's licence application guidance, which binds applicants for a BNPL licence. Open the Rules themselves for substantive BNPL definitions, scope and conduct obligations; this node gives the licensing cross-reference.
