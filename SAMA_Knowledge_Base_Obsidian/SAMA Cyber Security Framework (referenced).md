# SAMA Cyber Security Framework (referenced)

A cross-reference node: the IT Governance Framework repeatedly defers to the separate SAMA Cyber Security Framework for security-related controls, notably requiring the cyber security function to review and approve changes to information assets before Change Advisory Board submission and requiring change security requirements to be defined and tested per that framework. It signals that IT governance obligations sit alongside, and do not displace, cyber security obligations on the same Member Organizations. Use it to trace which requirement set governs a security control question.
