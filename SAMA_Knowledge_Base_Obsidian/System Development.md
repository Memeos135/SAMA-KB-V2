# System Development

Provision of the SAMA IT Governance Framework requiring Member Organizations to document, approve and implement a system development methodology so that development of their systems is strictly controlled. It sets expectations on development approach, secure coding standards, testing types, version control, quality control, data migration, documentation and end-user training, plus an approved low-level system design document and secure code review (or an independent assurance statement where source code is unavailable). Binds Member Organizations supervised by SAMA, including where development is outsourced to vendors.
