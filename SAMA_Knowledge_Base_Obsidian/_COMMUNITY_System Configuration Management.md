# System Configuration Management

## Why this community

Baseline control over the configuration of systems — establishing, approving and maintaining secure configuration standards as part of IT and cyber control expectations.

## How members connect

- Standalone node in this extract: it carries a single control obligation without internal cross-references in the graph.
- Read alongside the change and patch control cluster, since configuration baselines are what change controls protect.
- Its meaning depends on the parent IT governance / cyber framework definitions rather than on peer nodes.
