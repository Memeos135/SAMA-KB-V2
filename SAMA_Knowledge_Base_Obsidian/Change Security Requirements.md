# Change Security Requirements

Provision requiring cyber security requirements to be defined and fully tested in a test environment for all information system changes, so vulnerabilities are identified and mitigated before production deployment. It expressly links the change management process to the SAMA Cyber Security Framework for defining, testing and implementing those security requirements. Binds Member Organizations and creates a cross-reference between the IT governance and cyber security regimes.

**Regimes:** governance/risk
