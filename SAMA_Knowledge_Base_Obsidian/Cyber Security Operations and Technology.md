# Cyber Security Operations and Technology

The Cyber Security Operations and Technology domain of the Cyber Resilience Fundamental Requirements, one of the framework's core control areas covering day-to-day protective and detective security practices, supported by the framework's glossary definitions (cyber security incident, incident management, cyber security policy, cyber security risk). Applies to entities in scope of the Fundamental Requirements, principally newly established and sandbox-stage firms supervised by SAMA. Open this node for the operational control expectations rather than governance or continuity obligations.
