# Portfolio Compression

## Why this community

Portfolio compression as a risk-mitigation technique: the duty to periodically assess and, where appropriate, run compression exercises to reduce gross notional and outstanding contract counts in non-cleared derivative portfolios.

## How members connect

- Standalone node in this graph; its legal effect is a conditional duty (assess, and act if criteria such as portfolio size or number of outstanding trades are met), not an unconditional one.
- Operates on the same portfolio construct used by reconciliation and dispute-resolution duties, so scope definitions should be read consistently across those risk-mitigation obligations.
- Compression outcomes change the reportable population, linking it downstream to trade-reporting obligations.
