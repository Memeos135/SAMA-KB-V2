# Template KM1: Key Metrics

The consolidated-level key metrics template giving a five-quarter time series of a bank's available capital, RWA (including pre-floor figures), risk-based and leverage ratios, LCR and NSFR, plus fully loaded expected credit loss variants where ECL transitional arrangements are applied. Instructions fix the treatment of pre-floor and fully loaded figures and set cross-references linking KM1 cells to CC1 and OV1. Mandatory quarterly for all banks in SAMA's Pillar 3 scope; the related TLAC template KM2 applies only if SAMA specifies.

**Regimes:** banking prudential, governance/risk
