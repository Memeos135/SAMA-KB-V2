# Counter-Fraud Framework (CFF)

The parent instrument: SAMA's Counter-Fraud Framework setting mandatory control requirements across governance, prevention, detection and response, plus a glossary of defined terms (Counter-Fraud Programme, Policy, Culture, Governance, CFGC, Fraud, Employee, Electronic Money, EMI). It assigns ultimate responsibility to the Board and requires a quarterly-meeting Counter-Fraud Governance Committee and coordination with cyber security and financial crime functions. Binds Member Organizations supervised by SAMA, proportionate to size and nature of business.

**Regimes:** governance/risk, AML/CTF, payments, banking prudential

- **What this link tells you:** For any question about what the Counter-Fraud Framework requires in practice, the Framework operates as the umbrella instrument and the Fundamental Requirements are the baseline control set it invokes. This is a hierarchy relationship within one SAMA instrument: the Framework sets scope, applicability to Member Organizations and governing intent, while the Fundamental Requirements state the minimum obligations that must be met regardless of the entity's risk profile. A reader should treat the Fundamental Requirements as the enforceable floor and not as optional guidance under the Framework.
