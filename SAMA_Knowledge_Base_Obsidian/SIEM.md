# SIEM

Glossary and control node covering SIEM (security information and event management) and related defined terms within the SAMA Cyber Security Framework, read together with the cyber security event management requirements. Those requirements oblige Member Organizations to define, approve and implement a security event management process and monitoring standard, staff a dedicated SOC with 24x7 monitoring in a restricted area, and detect and handle malicious code, anomalies and suspicious events; adjacent controls include SMS notification to customers for retail/personal financial transactions and for adding, modifying or activating beneficiaries.

**Regimes:** governance/risk, payments
