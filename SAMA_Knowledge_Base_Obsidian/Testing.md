# Testing

Sub-provision of the system change management chapter of the SAMA IT Governance Framework setting minimum testing expectations before changes enter production. It covers documented test cases and attributes, unit, system integration, stress, security and user acceptance testing, use of a separate test environment, formal business user acceptance, retention of UAT results, third-party certification where applicable, and a prohibition on using production data for testing (sanitized data only). Binds Member Organizations; the data-handling restriction has confidentiality/data-protection consequences.

**Regimes:** governance/risk, data/credit info
