# Application Security

A control area within the SAMA Cyber Security Framework addressing security of applications, framed by the Framework's maturity model and by the requirement for an approved cyber security policy covering asset classification, ownership, risk assessment, awareness, regulatory/contractual compliance and breach reporting. Board-level responsibility and defined cyber security roles apply. It binds Member Organizations subject to SAMA supervision.

**Regimes:** governance/risk
