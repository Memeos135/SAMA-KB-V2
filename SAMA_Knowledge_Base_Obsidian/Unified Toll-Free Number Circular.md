# Unified Toll-Free Number Circular

A SAMA circular reaffirming that all supervised financial institutions must maintain customer communication channels and replace the existing unified customer-service number (920) with the unified toll-free number (800) for all customer segments. It supplements an earlier SAMA circular on making contact channels available. It binds all financial institutions under SAMA supervision.

**Regimes:** consumer protection, governance/risk
