# Application Security

## Why this community

Application security requirements — secure development, testing and maintenance obligations for in-house and acquired applications used in regulated financial activity.

## How members connect

- Single-node cluster: a discrete control domain in the cyber security framework, expressed as requirements on the member organisation across the application lifecycle.
- Where applications are vendor-supplied or hosted, the obligation persists with the regulated entity and interacts with outsourcing and third-party risk rules.
- Compliance evidence is typically surfaced through the audit and review obligations, creating a practical dependency on those assurance clusters.
