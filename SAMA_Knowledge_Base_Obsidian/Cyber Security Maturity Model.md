# Cyber Security Maturity Model

Concept node for the six-level cyber security maturity model (0 Non-existent through 5) used by SAMA to measure a Member Organization's compliance with the Cyber Security Framework. Levels are cumulative: a Member Organization must satisfy all criteria of lower levels before attaining level 3, 4 or 5, with level 3 requiring defined, approved, formally implemented and demonstrable controls. Determines the benchmark against which supervisory assessment and self-assessment outcomes are expressed.

**Regimes:** governance/risk, banking prudential
