# Third Party Cyber Security

Framework domain (section 3.4) requiring that the same level of cyber security protection applied inside a Member Organization is achieved at third parties it relies on, with third parties defined broadly to include information service providers, outsourcing and cloud providers, vendors, suppliers and government agencies. It sets how cyber security requirements with third parties are organised, implemented and monitored, and is the parent for contract/vendor management, outsourcing and cloud computing controls. Binds SAMA-supervised Member Organizations; accountability remains with the Board.

**Regimes:** governance/risk
