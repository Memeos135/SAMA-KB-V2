# Cyber Security Training

Node covering cyber security training expectations under SAMA's Cyber Security Framework, closely tied to the awareness programme and to the framework's roles-and-responsibilities requirements (board accountability, defined general and specific cyber security responsibilities). It supports the expectation that staff and stakeholders are equipped to apply cyber security controls consistently. Binds SAMA-supervised Member Organizations; performance is assessed via the maturity model.
