# Template CR9: IRB Backtesting of PD per Portfolio

Pillar 3 disclosure template CR9 requiring annual backtesting of probability of default estimates against realised obligor default rates, per regulatory portfolio and PD range, using at least a five-year average annual default rate. It applies to any SAMA-approved model or model combination used to generate PD for IRB capital calculations, with commentary on model scope and RWA coverage. Mandatory for SAMA-licensed banks using F-IRB and/or A-IRB, with separate template sets where both approaches are used.

**Regimes:** banking prudential, governance/risk
