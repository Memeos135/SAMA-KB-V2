# Detailed Loss Event Type Classification

Concept node covering the specific criteria for building the standardised approach loss data set: gross loss, net loss and recovery definitions, what must be included in gross loss (direct P&L charges, consequential costs, provisions, pending losses), reference date and grouped losses. It determines which operational loss events count and how they are measured for capital and Pillar 3 loss templates; binds banks using loss data in the operational risk capital calculation.

**Regimes:** banking prudential, governance/risk
