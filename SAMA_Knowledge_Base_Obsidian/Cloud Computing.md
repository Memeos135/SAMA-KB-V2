# Cloud Computing

Node within the SAMA Cyber Security Framework covering outsourcing and cloud computing controls for Member Organizations (SAMA-supervised financial institutions). It sets the expectation of a defined, approved and monitored cloud policy and process for hybrid and public cloud only (private/internal cloud excluded), with prior SAMA approval before material outsourcing and before using cloud services or signing a cloud contract, plus contractual coverage of data location (in principle inside Saudi Arabia, otherwise explicit SAMA approval), no secondary use of data, security controls, logical data segregation, business continuity, audit/review/examination rights and exit arrangements. It binds the Member Organization, which remains accountable for controls executed by the service provider.

**Regimes:** governance/risk, banking prudential
