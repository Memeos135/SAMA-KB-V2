# Cyber Security in Project Management

Section of SAMA's Cyber Security Framework requiring Member Organizations to embed cyber security into project management methodology and project governance. It expects cyber security objectives in project objectives, involvement of the cyber security function across all project phases, an initial risk assessment, registration and tracking of cyber security risks, allocated responsibilities, and an independent internal or external review. Binds SAMA-supervised Member Organizations and is assessed against the framework's six-level maturity model.

**Regimes:** governance/risk
