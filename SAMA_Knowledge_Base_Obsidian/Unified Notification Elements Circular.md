# Unified Notification Elements Circular

SAMA circular standardising the content of transaction notification messages sent to customers, extending earlier instructions on mada card notifications to all financial transactions on accounts, memberships and e-wallets. Attached tables set out the minimum data elements per transaction type (card purchases domestic/international, ATM withdrawals, deposits, cheques, domestic and international transfers, online purchases, bill payments, financing disbursement and instalments, fees, refunds/reversals, mobile app and wallet transactions) and a unified Arabic/English terminology list. Institutions must send notifications for all financial transactions within 15 days and file an implementation plan within two weeks; binds banks, payment service providers and category (A) exchange companies.

**Regimes:** consumer protection, payments
