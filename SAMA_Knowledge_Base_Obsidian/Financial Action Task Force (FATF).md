# Financial Action Task Force (FATF)

Concept node for the Financial Action Task Force as used in SAMA's AML/CTF rules, principally in the transaction and activity monitoring section (Section 7): institutions must develop and continually update ML/TF indicators and typologies proportionate to their business, observing instructions from SAMA, the PCCML, the PCCT and international bodies such as FATF. It signals that FATF standards and typologies are an expected input to a risk-based monitoring framework, not merely background. Binds SAMA-supervised financial institutions.

**Regimes:** AML/CTF, governance/risk
