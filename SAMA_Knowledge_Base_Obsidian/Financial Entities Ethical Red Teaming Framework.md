# Financial Entities Ethical Red Teaming Framework

A SAMA circular adopting the Financial Entities Ethical Red Teaming Framework, a supervisory framework for intelligence-led simulation of real-world cyber attack scenarios against supervised financial institutions. It establishes that SAMA will run periodic red-team exercises on institutions' live systems and expects institutions to conduct their own independent, periodic resilience testing consistent with the Cyber Security Framework. It is addressed to banks operating in the Kingdom, Saudi Payments and licensed payment companies, and insurance/reinsurance companies, with the framework itself distributed to compliance departments.

**Regimes:** governance/risk, payments, other
