# Framework Update Requests

## Why this community

The procedural route by which a supervised entity (or SAMA itself) seeks amendment of an existing framework's requirements, i.e. how binding rule text is changed rather than departed from.

## How members connect

- Single-node cluster describing a process rather than a substantive obligation.
- Pairs conceptually with the waiver process: update changes the rule for all addressees; waiver relaxes it for one addressee.
- Relevance is hierarchical - it sits at the framework-maintenance level above individual articles, so it governs the currency of any requirement cited from that framework.
