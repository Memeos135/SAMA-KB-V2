# BCBS Basel III LCR Document Jan 2013

Reference node for the Basel Committee's January 2013 standard on the Liquidity Coverage Ratio and liquidity risk monitoring tools, endorsed by the GHOS, which SAMA adopts as the substantive basis for its amended LCR framework. SAMA's guidance and prudential return cross-reference the BCBS paragraph numbering, so the international text supplies the detailed rules where SAMA's circular does not restate them. It is not itself a SAMA instrument but is incorporated by reference for Saudi banks.

**Regimes:** banking prudential
