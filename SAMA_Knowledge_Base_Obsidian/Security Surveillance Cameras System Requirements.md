# Security Surveillance Cameras System Requirements

SAMA circular reaffirming that supervised financial institutions must apply the Law on the Use of Security Surveillance Cameras, its Ministry of Interior Implementing Regulation, and the associated security conditions and general technical specifications for installing surveillance camera systems. It notes that financial institutions are classified among high-sensitivity sites under the site-sensitivity classification, and also requires compliance with SAMA's Security and Safety Guide for the financial sector. Binding on all financial institutions supervised by SAMA.
