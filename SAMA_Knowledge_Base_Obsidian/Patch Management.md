# Patch Management

Subdomain 3.4.9 of SAMA's IT Governance Framework setting the principle and control requirements for a defined, approved, implemented and communicated patch management process so that functional and non-functional patches are applied in a timely way to close vulnerabilities. It sits within the System Change Management domain alongside system configuration management (CMDB, configuration items) and change windows. It binds Member Organizations supervised by SAMA and is assessed through the framework's self-assessment and maturity model.

**Regimes:** governance/risk
