# SAMA Cyber Security Framework v1.0

SAMA's Cyber Security Framework, the sector-wide instrument setting principles, objectives and control considerations for cyber security across domains (leadership and governance, risk management and compliance, operations, third parties), together with a maturity model used to measure compliance. Obligations attach to Member Organizations supervised by SAMA, with ultimate accountability placed on the Board of Directors, including approving policy and allocating budget. Central reference for any question on cyber security governance duties, policy content requirements and assessed maturity levels.

**Regimes:** governance/risk, banking prudential
