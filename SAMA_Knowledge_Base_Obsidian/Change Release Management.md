# Change Release Management

Sub-provision of the SAMA IT Governance Framework governing how approved changes are released into production, including the requirement that changes be introduced within an agreed change window, with a separate approval process for exceptions which should rarely be permitted absent compelling reasons. It sits within the wider change management chapter requiring changes to be classified, tested and approved before deployment. Binds Member Organizations.

**Regimes:** governance/risk
